# جداول (JadvalApps)

برنامه هفتگی دانشجو — فارسی و راست‌به‌چپ. درس‌های ترم را ثبت کنید، تداخل زمانی را خودکار ببینید، و جدول هفتگی را به PDF / تصویر / لینک اشتراک خروجی بگیرید.

🌐 نسخه وب: https://amirelahpour.github.io/jadvalapps/

## اجرا

```bash
npm install
npx expo start          # موبایل (Expo Go) و وب
npx expo start --web    # فقط وب
```

## ویژگی‌ها

- فرم افزودن/ویرایش درس: کد، نام، استاد، واحد، رنگ، آزمون (تقویم جلالی)، جلسات هفتگی
- انتخاب ساعت چرخ‌گردان (wheel) با پیش‌تنظیم‌ها، انتخاب تاریخ جلالی
- تشخیص خودکار تداخل زمانی هنگام ذخیره (با نام درس متداخل)
- تب‌های روزانه (شنبه تا پنجشنبه) + نشان «امروز»
- خروجی: لینک اشتراک، PDF، تصویر PNG جدول کامل، پشتیبان JSON + بازیابی
- تم روشن/تیره، فونت وزیرمتن
- همه داده‌ها فقط روی دستگاه (localStorage / AsyncStorage) — بدون سرور

## تکنولوژی

Expo (React Native + TypeScript) — خروجی iOS، اندروید و وب از یک کدبیس.
